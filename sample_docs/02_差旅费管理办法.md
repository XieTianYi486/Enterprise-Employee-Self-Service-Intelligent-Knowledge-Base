# 差旅费管理办法

## 第一章 总则

### 第一条 目的

为规范公司差旅费用管理，合理控制差旅成本，保障出差人员工作需求，根据国家相关财务法规，结合公司实际，制定本办法。

### 第二条 适用范围

本办法适用于公司全体员工因公务需要赴外埠（离开常驻工作地）出差所产生的费用管理。常驻工作地是指劳动合同中约定的工作城市。

### 第三条 基本原则

1. 实事求是：出差须有明确的工作任务和必要性，严禁无实质内容的出差
2. 厉行节约：在保障工作需求的前提下，合理控制差旅费用
3. 事前审批：所有出差须提前申请并获得批准
4. 实报实销：差旅费用需提供真实有效票据，按标准报销

## 第二章 出差审批

### 第四条 审批权限

1. 普通员工出差：由部门经理审批
2. 部门经理出差：由分管总监审批
3. 总监及以上人员出差：由分管副总裁审批
4. 副总裁及以上人员出差：由总裁/CEO审批
5. 出国（境）出差：所有人员均须总裁审批

### 第五条 出差申请流程

1. 员工在OA系统提交《出差申请单》，填写出差事由、目的地、时间、预计费用等
2. 差旅时间超过5天或预计费用超过1万元的，须附出差计划书
3. 多人共同出差的，由带队人员统一提交申请，列出所有出差人员名单
4. 审批通过后，出差人员可凭审批单预订交通工具和住宿
5. 紧急出差可先行电话请示，出差返回后3个工作日内补办手续

### 第六条 出差借款

1. 出差预计费用超过3000元的，可申请出差借款
2. 借款金额不超过预计费用的80%
3. 出差返回后10个工作日内凭票据冲销借款，多退少补
4. 前次借款未结清的，原则上不得再次借款

## 第三章 交通费用标准

### 第七条 城市间交通

| 交通工具 | 总监及以上 | 经理级 | 普通员工 |
|---------|----------|-------|---------|
| 飞机 | 商务舱 | 经济舱 | 经济舱 |
| 高铁/动车 | 商务座 | 一等座 | 二等座 |
| 火车（普速） | 软卧 | 硬卧 | 硬卧 |
| 轮船 | 一等舱 | 二等舱 | 三等舱 |
| 长途汽车 | 实报实销 | 实报实销 | 实报实销 |

### 第八条 机票预订

1. 机票由公司指定的商旅服务商统一预订，不得通过非指定渠道预订
2. 提前7天以上订票可享受早鸟折扣，鼓励出差人员提前规划行程
3. 不得预订全价机票（F/Y舱），如有特殊情况须在申请时说明
4. 退票、改签产生的手续费，因公原因由公司承担，因私原因由个人承担
5. 机票预订以经济实惠为原则，同一时段内优先选择低价航班

### 第九条 市内交通

1. 出差目的地市内交通以公共交通（地铁、公交）为主，费用实报实销
2. 因工作需要或携带大量文件设备时，可选择出租车或网约车
3. 出差期间每日市内交通费上限：一线城市（北上广深）80元/天，其他城市50元/天
4. 多人同行的，应合理安排共乘，减少交通费用
5. 因公需租车的，须提前在出差申请中说明，并选择经济型车辆

## 第四章 住宿费用标准

### 第十条 住宿标准

| 城市类别 | 总监及以上 | 经理级 | 普通员工 |
|---------|----------|-------|---------|
| 一线城市（北上广深） | 800元/天 | 500元/天 | 400元/天 |
| 二线城市（省会及计划单列市） | 600元/天 | 400元/天 | 300元/天 |
| 其他城市 | 400元/天 | 300元/天 | 250元/天 |

注：以上价格为含早价格。住宿费用超出标准的，超出部分由个人承担。

### 第十一条 住宿要求

1. 住宿酒店尽量选择协议酒店，享受公司协议价
2. 同性别的两名出差人员应合住标准间，节约住宿费用
3. 住宿天数按出差自然天数计算（出发日至返回日，含途中时间）
4. 住宿费按实际住宿天数计算，退房当日12:00前退房
5. 因特殊情况需入住超标准酒店，须提前在出差申请中说明并获批准

## 第五章 餐饮及其他费用

### 第十二条 伙食补助

1. 出差伙食补助标准：一线城市120元/天，其他城市100元/天
2. 伙食补助按自然天数计算，出差当天出发和返回当天的伙食补助按半天计算
3. 会议/培训已安排餐饮的，不再发放该时段伙食补助
4. 出差期间有商务宴请的，该餐次伙食补助不再发放
5. 伙食补助实行包干制，无需提供餐饮发票
6. 连续出差超过15天的，第16天起伙食补助按标准的80%发放

### 第十三条 接待与宴请

1. 出差期间因公需要宴请客户或合作伙伴，须提前申请并获批准
2. 宴请标准：人均不超过200元（含酒水）
3. 陪餐人数原则上不超过客人人数
4. 宴请报销须提供餐厅发票、消费明细和参与人员名单
5. 不得以任何理由报销高档烟酒、娱乐等费用

### 第十四条 通讯与杂费

1. 出差期间因公产生的快递费、资料打印费等，凭票据实报实销
2. 出差期间手机通讯费不单独报销（已含在月度通讯补贴中）
3. 出国（境）差旅的护照签证费、保险费、疫苗接种费等，凭票据实报实销
4. 出差人员应自行购买旅游意外险（已由公司统一投保的除外）

## 第六章 出国（境）差旅

### 第十五条 境外差旅额外规定

1. 境外差旅须提前至少15个工作日提交申请，包括详细的行程安排和预算
2. 出国人员须办理因公护照/签证，费用由公司承担
3. 境外住宿和伙食补助标准参照财政部《因公临时出国经费管理办法》执行
4. 境外差旅保险由公司统一购买
5. 出国人员须在出发前接受外事纪律和安全教育
6. 回国后5个工作日内提交出差报告

### 第十六条 境外货币使用

1. 出国人员可根据出差天数申领外币现金，限额为等值1000美元/人
2. 大额支出（住宿、会议等）使用公司公务信用卡结算
3. 境外消费应保存所有票据，报销时附中文简要说明
4. 外币报销按报销当日央行公布的汇率中间价折算为人民币
5. 未使用完的外币应在回国后3个工作日内交回财务部

## 第七章 报销管理

### 第十七条 报销基本规定

1. 出差返回后10个工作日内提交差旅费用报销申请，逾期不予受理
2. 报销须通过OA系统提交，填写《差旅费报销单》，上传电子发票或票据扫描件
3. 所有报销票据须真实、完整、清晰，发票抬头为公司全称及纳税人识别号
4. 电子发票（增值税电子普通发票、电子客票行程单等）可直接上传报销
5. 纸质票据须粘贴在A4纸上，按时间顺序排列

### 第十八条 报销凭证要求

1. 交通费：提供航空运输电子客票行程单/火车票/客运票
2. 住宿费：提供增值税专用发票（可抵扣）或增值税普通发票
3. 餐饮费：提供餐饮发票及消费明细
4. 会务费/培训费：提供正规发票及会议/培训通知
5. 其他费用：提供对应票据及情况说明

### 第十九条 票据丢失处理

1. 机票/火车票丢失：提供订票平台的电子行程单或购票记录截图
2. 住宿发票丢失：联系酒店补开发票或提供住宿流水单
3. 无法补开票据的：提供情况说明，经部门经理和财务经理审批后可酌情报销
4. 票据丢失需提供丢失说明，同一员工一年内丢失票据超过3次的，财务部重点关注

### 第二十条 报销审核与支付

1. 财务部收到报销申请后5个工作日内完成审核
2. 审核不通过的，退回申请人修改并说明原因
3. 审核通过后，每两周集中支付一次（每月15日和30日/31日）
4. 紧急报销可申请加急处理，3个工作日内完成支付
5. 全年累计出差费用超过部门预算的，超出部分需分管领导特批

## 第八章 违规处理

### 第二十一条 违规行为

以下行为属于违反差旅费管理规定：
1. 虚报出差天数、人数、费用
2. 提供虚假票据或涂改票据
3. 出差期间从事与公务无关的活动
4. 借出差名义外出旅游
5. 超出规定的标准消费且未获批准
6. 将个人消费以差旅名义报销
7. 已被招待/安排仍重复报销相应费用

### 第二十二条 处理措施

1. 虚报差旅费用的，追回报销款项，处以虚报金额2倍的罚款
2. 情节严重或两次以上违规的，视为严重违纪，公司可解除劳动合同
3. 审批人未严格审核导致违规报销的，审批人承担连带责任
4. 违规行为记入个人诚信档案，影响年度绩效评估和晋升

## 第九章 附则

### 第二十三条 特殊情形

1. 因紧急任务出差的，可按程序先行出差后补办审批手续
2. 残疾人、孕期女员工出差的，在住宿和交通标准上可适当上调一档
3. 长期驻外（超过一个月）的差旅费标准另行制定
4. 高管外事出访的礼遇标准另行制定

### 第二十四条 制度的解释和修订

本办法由财务部负责解释和修订。修订须报公司总经理批准后发布。

### 第二十五条 生效日期

本办法自2024年1月1日起施行，原《差旅费管理办法（2021版）》同时废止。
