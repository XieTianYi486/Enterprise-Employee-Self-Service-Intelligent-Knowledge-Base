# 绩效考核与晋升制度

## 第一章 总则

### 第一条 目的

为建立公平、公正、透明的绩效管理体系，客观评估员工工作表现，激励员工持续改进和提升，为薪酬调整、岗位晋升、培训发展提供依据，特制定本制度。

### 第二条 适用范围

本制度适用于公司全体正式员工（试用期员工参照执行）。

### 第三条 基本原则

1. 目标导向：以公司战略目标为牵引，层层分解到部门和个人
2. 客观公正：以事实和数据为依据，避免主观臆断
3. 持续沟通：考核过程中的双向沟通，主管与下属就目标、进展、改进保持持续对话
4. 结果应用：考核结果与薪酬、晋升、培训等充分挂钩
5. 持续改进：考核目的不是为了惩罚，而是帮助员工发现不足、持续进步

## 第二章 绩效考核体系

### 第四条 考核周期

| 考核类型 | 周期 | 时间节点 | 适用对象 |
|---------|------|---------|---------|
| 季度考核 | 每季度一次 | Q1:4月1-10日，Q2:7月1-10日，Q3:10月1-10日，Q4/年度:1月1-20日 | 全员 |
| 年度考核 | 每年一次 | 每年1月1日-20日（含Q4考核） | 全员 |
| 试用期考核 | 试用期结束前2周 | 试用期结束前 | 试用期员工 |
| 专项考核 | 项目/任务结束时 | 按需 | 项目制员工 |

### 第五条 考核维度与权重

**管理序列（M序列）：**

| 维度 | 权重 | 说明 |
|-----|------|------|
| 业绩目标达成 | 50% | 部门KPI、关键项目里程碑、业务指标完成情况 |
| 团队管理 | 25% | 团队建设、人才培养、员工敬业度、人才梯队建设 |
| 价值观与行为 | 15% | 公司核心价值观践行、职业道德、协作精神 |
| 创新与改进 | 10% | 管理创新、流程优化、成本节约贡献 |

**专业技术序列（P/T序列）：**

| 维度 | 权重 | 说明 |
|-----|------|------|
| 业绩目标达成 | 55% | 个人OKR/KPI完成情况、项目交付质量和时效 |
| 技术/业务能力 | 25% | 专业技能提升、知识分享、技术影响力 |
| 价值观与行为 | 15% | 责任心、团队合作、客户意识 |
| 创新与改进 | 5% | 技术突破、工具改进、专利贡献 |

### 第六条 考核等级分布

| 等级 | 定义 | 分数区间 | 强制比例 |
|-----|------|---------|---------|
| S（卓越） | 大幅超越目标，表现卓越 | ≥95分 | ≤5% |
| A（优秀） | 超越目标，表现优秀 | 85-94分 | ≤15% |
| B+（良好） | 达成目标，部分超越 | 75-84分 | ≤35% |
| B（胜任） | 基本达成目标 | 65-74分 | 不限制 |
| C（待改进） | 部分目标未达成，需改进 | 55-64分 | ≥5% |
| D（不合格） | 多数目标未达成 | ＜55分 | ≥2% |

注：部门人数少于5人的，不强制D等级；连续两次考核为C或一次考核为D的进入绩效改进计划（PIP）。

### 第七条 考核流程

1. **目标设定（考核周期开始前5个工作日）：** 员工与直属上级在系统中共同设定当期目标
2. **自评（考核周期结束后3个工作日）：** 员工在系统完成自评，对照目标逐项填写完成情况
3. **上级评估（自评结束后5个工作日）：** 直属上级完成评估打分和评语
4. **隔级校准（上级评估后3个工作日）：** 隔级上级审核评分分布，校正过松或过严的评估
5. **结果反馈（校准后5个工作日）：** 直属上级与员工一对一绩效面谈（不少于30分钟），介绍评估结果，肯定成绩并指出改进方向
6. **HR复核与归档：** HR部门抽查不低于10%的考核结果进行复核
7. **申诉期（结果反馈后5个工作日）：** 员工对结果有异议可提交绩效申诉

## 第三章 绩效结果应用

### 第八条 绩效薪酬

| 考核等级 | 季度绩效系数 | 年度奖金系数 |
|---------|-----------|-----------|
| S | 1.5 | 2.0-3.0 |
| A | 1.2 | 1.5-2.0 |
| B+ | 1.0 | 1.0-1.5 |
| B | 0.8 | 0.6-1.0 |
| C | 0.5 | 0.3-0.5 |
| D | 0 | 0 |

### 第九条 晋升资格

1. 最近两次绩效考核均为B+及以上方可申请晋升
2. 破格晋升须最近一次考核为S（卓越）
3. 考核为C等级者暂停晋升资格一年
4. 考核为D等级者公司有权进行调岗、降级处理

### 第十条 绩效改进计划（PIP）

1. 触发条件：
   - 连续两次季度考核为C
   - 一次考核为D
2. PIP期限：1-3个月
3. PIP内容：明确改进目标、时间表、检查节点、辅导支持
4. PIP期间直属上级每周至少与员工进行一次进展沟通
5. PIP结束评估：
   - 达标：恢复正常考核流程
   - 不达标：进入岗位调整或劳动关系解除流程

## 第四章 晋升管理

### 第十一条 晋升通道

详见《员工手册》第六章第十七条。

### 第十二条 晋升基本条件

| 晋升方向 | 在当前职级年限 | 最近两次考核 | 其他条件 |
|---------|-------------|-----------|---------|
| P1→P2 / T1→T2 | ≥1年 | 均为B+及以上 | 通过岗位技能认证 |
| P2→P3 / T2→T3 | ≥1.5年 | 至少一次A | 带教过至少1名新人/独立负责过重要模块 |
| P3→P4 / T3→T4 | ≥2年 | 至少一次A | 主导过跨部门项目，有技术文章/分享 |
| P4→P5 / T4→T5 | ≥2.5年 | 至少一次S | 在业界有一定影响力（专利/大会演讲/开源贡献） |
| M1→M2 | ≥1.5年 | 至少一次A | 团队≥3人，团队无离职率异常 |
| M2→M3 | ≥2年 | 至少一次A | 团队≥8人，培养出至少1名M1 |
| M3→M4 | ≥2.5年 | 至少一次S | 管过2个不同团队或跨地域团队管理经验 |

### 第十三条 晋升评审流程

1. **提名阶段（晋升月前一个月15日前）：** 部门负责人提名或员工自荐，提交提名表
2. **资格审核（提名后5个工作日）：** HR审核基本条件
3. **述职答辩（资格审核后2周内）：** 晋升评审委员会（部门负责人+HR+业务专家+隔级上级）听取候选人述职，进行问答
4. **投票表决：** 评审委员会投票，2/3以上同意即为通过
5. **结果公示（5个工作日）：** 公示晋升名单，接受全员监督
6. **晋升任命：** 公示无异议后，次月1日生效

### 第十四条 晋升后管理

1. 晋升后试用考察期为3个月（原薪酬不变，考察通过后调整薪酬）
2. 考察通过标准：完成晋升岗位的目标任务，无重大失误
3. 考察不通过的，返回原岗位或调整为其他适合岗位
4. 晋升后薪酬调整幅度：原则上10%-25%（符合市场水平）
5. 跨序列晋升（如P3转M1）：参照目标序列的晋升条件

## 第五章 奖惩管理

### 第十五条 奖励类别

| 奖励类别 | 奖励形式 | 触发条件 |
|---------|---------|---------|
| 即时奖励 | 200-2000元现金 | 特定事件（如攻克技术难题、获得客户表扬） |
| 季度之星 | 3000元+荣誉证书 | 季度表现突出员工（每部门≤1名，公司≤10名） |
| 年度优秀员工 | 10000元+奖杯+旅游 | 年度考核S级+全员投票前10名 |
| 总裁特别奖 | 20000-50000元 | 做出重大贡献（技术创新突破、重大项目成功、为公司挽回重大损失） |
| 创新奖 | 5000-20000元 | 专利授权、技术创新为公司创造显著价值（年度节约/增收≥50万元） |
| 伯乐奖 | 2000-5000元 | 成功推荐人才入职且通过试用期（经理级5000元，其他2000元） |

### 第十六条 处罚类别

| 处罚类别 | 处罚形式 | 影响 |
|---------|---------|------|
| 口头警告 | 直接上级/HR口头提醒 | 不计入档案 |
| 书面警告 | 书面通知（HR系统记录） | 影响当年评优资格 |
| 通报批评 | 部门/公司内部通报 | 影响绩效考核、当年不得晋升 |
| 降级降薪 | 降至下一职级（薪资相应下调） | 影响期12个月 |
| 解除劳动合同 | 终止劳动关系 | 离职证明如实记录 |

## 第六章 绩效申诉

### 第十七条 申诉条件

员工对考核结果有异议且符合以下条件之一的，可提起申诉：
1. 考核程序存在明显违规
2. 考核评价基于明显失实的事实信息
3. 考核中存在个人偏见或打击报复

### 第十八条 申诉流程

1. 在绩效反馈面谈后5个工作日内通过HR系统提交《绩效考核申诉表》
2. HR部门收到申诉后3个工作日内确认是否受理
3. 受理后15个工作日内完成调查、组织复议
4. 复议结果为最终考核结果，HR书面告知申诉人
5. 申诉期间原考核结果的执行不受影响

## 第七章 附则

### 第十九条 制度的维护

本制度由人力资源部负责解释和修订。每年1月可根据上一年度实施情况和员工反馈进行一次修订。
