# IT设备使用规范

## 第一章 总则

### 第一条 目的

为规范公司IT设备的使用管理，保障IT资产安全，提高设备使用效率，降低运维成本，特制定本规范。

### 第二条 适用范围

本规范适用于公司采购、配发的所有IT设备，包括但不限于：台式电脑、笔记本电脑、显示器、打印机、扫描仪、复印机、服务器、网络设备、移动终端（手机、平板）、存储设备、会议设备等。

### 第三条 管理职责

1. IT部门：负责IT设备的采购选型、资产登记、安装配置、运维支持、故障维修和报废处置
2. 行政部门：负责IT设备的固定资产账务管理、盘点核查
3. 使用人：负责所领用IT设备的日常保管、规范使用，设备损坏或丢失的须及时报告
4. 部门负责人：负责本部门IT设备需求的审批和设备使用情况的监督管理

## 第二章 设备采购与配置标准

### 第四条 设备配置标准

IT部门根据岗位工作需求制定设备配置标准，按年度评审和更新：

| 人员类别 | 计算机配置 | 显示器 | 其他外设 |
|---------|----------|-------|---------|
| 行政/文职/销售 | 办公型笔记本（i5/16GB/512GB） | 24寸 ×1 | 键鼠套装 |
| 软件开发工程师 | 开发型笔记本（i7/32GB/1TB） | 27寸4K ×2 | 开发专用键鼠、耳机 |
| 设计师 | 设计型笔记本/工作站（i9/64GB/1TB/独显） | 27寸4K ×2 | 专业数位板、校色仪 |
| 数据/算法工程师 | 高性能工作站（至强/128GB/2TB/GPU） | 27寸4K ×2 | GPU服务器登录权限 |
| 部门经理及以上 | 高端商务笔记本（i7/32GB/1TB） | 27寸 ×1或24寸×2 | 视频会议套件 |

### 第五条 设备采购流程

1. 使用人/部门在IT服务台提交设备需求申请
2. 部门负责人审批（确认必要性）
3. IT部门审核（确认技术规格和兼容性）
4. 预算额度内由IT部门直接采购；超预算的须财务部加签
5. IT部门收货验收、登记资产编号、纳入资产管理系统
6. IT部门完成系统安装和标准化配置
7. 使用人签收领用

### 第六条 设备更换周期

1. 笔记本电脑：3年更换一次（开发/设计岗位可缩短至2年）
2. 台式电脑/工作站：4年更换一次
3. 显示器：5年更换一次
4. 服务器：5年更换一次，核心业务服务器可提前至4年
5. 移动设备（手机/平板）：2年更换一次
6. 提前更换条件：设备故障且维修成本超过设备残值的50%
7. 超过更换周期的设备可申请更换，但仍可正常使用的可继续使用

## 第三章 设备使用管理

### 第七条 设备领用与归还

1. 新员工入职时由IT部门配置好设备后发放，员工签收《IT设备领用登记表》
2. 员工岗位变动时须将旧岗设备归还IT部门，新岗按标准重新配置
3. 员工离职时须将所有IT设备归还IT部门，设备完好方可办理离职手续
4. 临时借用设备（如投影仪、会议终端）须登记并按时归还，借用期限不超过5个工作日
5. 设备转借他人须经IT部门批准并更新资产登记信息

### 第八条 日常使用规范

1. 公司配发设备为工作用途，不得用于非法活动或私人营利活动
2. 设备须安装公司指定的操作系统版本和安全补丁，不得擅自重装系统或升级
3. 软件安装须通过公司应用商店或IT部门授权，禁止安装盗版软件、破解软件
4. 工作文件须保存在公司指定的云存储或网络驱动器中，不建议存储在本地桌面
5. 设备使用人应定期清理无用文件，保持磁盘可用空间不低于20%
6. 严禁在公司设备上接入未经IT部门安全检测的外部设备（如来源不明的U盘）
7. 笔记本电脑移动办公时注意防摔、防盗、防液体泼溅
8. 就餐、饮水时应与设备保持安全距离，避免液体进入设备

### 第九条 账号与密码管理

1. 使用人须设置开机密码，密码规则符合公司安全策略要求
2. 账号和密码仅限本人使用，严禁将登录凭证告知他人或为他人登录提供便利
3. 员工忘记密码的，联系IT服务台使用工号+身份证后六位验证身份后重置
4. 共享账号仅用于公共设备（如会议室的演示电脑），由IT部门统一管理
5. 第三方厂商远程支持时，须临时开启专用账号，支持结束后立即禁用
6. 域账号有过期机制，连续90天未使用的账号自动锁定

### 第十条 移动设备管理

1. 公司配发的手机须注册MDM（移动设备管理），接受公司安全策略管控
2. 不得破解（越狱/Root）公司配发的移动设备
3. 公司手机上不得安装来自非官方应用商店的App
4. 使用公司手机上安装的App时须注意授予的权限，禁止授予不必要的敏感权限
5. 移动设备遗失后须通过"查找设备"功能远程锁定并擦除数据
6. 员工个人设备（BYOD）需接入公司系统的，须安装公司指定的MDM配置文件

## 第四章 软件与许可管理

### 第十一条 软件安装权限

1. IT部门维护公司软件白名单，白名单内的软件员工可自行安装
2. 白名单外的软件须提交申请，经IT部门安全评估和合规审核后安装
3. 开发工具类软件由IT部门根据开发团队需求统一部署
4. 未经授权不得在公司设备上安装以下软件：
   - 盗版或未获得合法授权的软件
   - P2P下载软件（如BitTorrent、迅雷等）
   - 翻墙软件（未经IT部门批准的VPN/代理工具）
   - 挖矿软件、游戏软件
   - 来源不明的共享软件/免费软件

### 第十二条 软件许可证管理

1. IT部门统一管理所有商业软件的许可证
2. 部门级软件许可证由部门文员配合IT部门管理
3. 员工离职或岗位变动后，其占用的许可证须在5个工作日内回收
4. 年度软件许可证审计（3月），清点并优化许可证使用情况
5. 开源软件使用须遵守其许可证规定，GPL类许可证须IT部门审核后方可使用
6. 私自安装未经授权的商业软件，造成的版权纠纷由个人承担

### 第十三条 邮件与通讯工具使用

1. 公司电子邮箱为正式工作沟通渠道，外部商务沟通须使用公司邮箱
2. 即时通讯使用企业微信（内部沟通）和授权的协作平台
3. 邮件附件大小超过20MB的，使用大文件分享链接代替
4. 发送给超过50人的全员邮件须经部门负责人批准
5. 不准利用公司邮件系统发送连锁信、垃圾邮件、广告和个人信息
6. 敏感信息不得通过个人微信、QQ等非授权渠道传输

### 第十四条 视频会议规范

1. 公司标准视频会议平台为腾讯会议/飞书（按团队具体使用）
2. 重要会议须开启等候室和会议密码
3. 录制会议须提前告知参会者并征得同意
4. 会议录制文件存储在授权平台，保存期不超过6个月
5. 外部参会者的会议链接须设置有效期和参会权限
6. 视频会议时注意背景环境、着装仪容，确保麦克风和摄像头处于合适的收音/拍摄角度

## 第五章 数据存储与备份

### 第十五条 文件存储规范

1. 工作文件统一存储在公司指定的云盘/文件服务器上，按部门和个人分级管理
2. 个人工作目录（Home Drive）配额为50GB，超过配额须申请扩容
3. 部门共享目录用于团队文件的共享和协作，权限由部门负责人管理
4. 严禁将可识别个人信息（如身份证扫描件）直接存储在共享目录中
5. 文件命名规范：`[项目名/类别]_[内容简述]_[日期]_[版本号].[扩展名]`，如：`智能问答_架构设计_20240115_v1.0.docx`
6. 使用日期/版本号避免使用"最终版""新建""副本"等无意义命名

### 第十六条 数据备份

1. 文件服务器数据每日自动备份，备份保留30天
2. 笔记本电脑本地数据建议同步到云存储，重要文档至少每周手动备份一次
3. 离职员工的个人工作目录保留30天后自动清理
4. 离职员工的数据由其主管确认后，将必要数据迁移至接任者
5. 过期的项目数据由项目负责人确认后归档或清理

## 第六章 故障处理与技术支持

### 第十七条 故障报修

1. IT设备故障通过IT服务台（企业微信/Web Portal/电话）提交工单
2. 工单须包含设备型号、故障现象描述、故障发生时间、影响范围
3. IT部门按故障严重程度确定响应时间：
   - 紧急（影响多人工作/生产系统故障）：30分钟内响应
   - 高（个人无法工作）：1小时内响应
   - 中（部分功能异常但有备用方案）：4小时内响应
   - 低（小问题/咨询类）：1个工作日内响应
4. IT部门每周五发布本周故障处理汇总和常见问题解决方案

### 第十八条 设备维修与备机

1. 保修期内设备由IT部门联系厂商维修，维修周期一般3-7个工作日
2. 维修期间IT部门提供备机（基础配置），保障工作连续性
3. 过保设备由IT部门评估：维修成本＜残值50%则维修，否则按报废处置
4. 人为损坏（进水、摔坏等），维修费用由使用人承担（具体比例按事故原因判定）
5. 硬盘等存储设备故障需要维修的，须先拆卸并单独存放，确保数据安全

## 第七章 设备报废与回收

### 第十九条 报废条件

IT设备满足以下条件之一的可申请报废：
1. 超过规定使用年限且无法满足工作需求
2. 设备损坏，且维修成本超过设备残值的50%
3. 技术淘汰，无法运行当前工作的必要软件
4. 配件停产，无法获取维修配件
5. 安全原因（如存在无法修复的固件漏洞）

### 第二十条 报废流程

1. 使用人/IT部门提交《IT设备报废申请表》
2. IT部门进行技术鉴定（确认是否需报废）
3. 行政部门进行资产核销
4. 报废设备由IT部门统一回收
5. 存储介质须进行安全数据擦除（部门级以上使用DoD 5220.22-M标准多次覆写或物理粉碎）
6. 设备交由签约的环保回收商处理，符合电子废弃物处置规定
7. 涉及公司保密数据的设备，须信息安全部门监督销毁全过程
