# 劳动合同与入职管理制度

## 第一章 总则

### 第一条 目的

为规范公司劳动用工管理，维护公司和员工的合法权益，构建和谐稳定的劳动关系，根据《中华人民共和国劳动法》《中华人民共和国劳动合同法》等法律法规，制定本制度。

### 第二条 适用范围

本制度适用于公司所有员工（含试用期员工、劳务派遣人员、非全日制用工人员）的劳动合同签订、履行、变更、续订、解除和终止。

### 第三条 管理职责

1. 人力资源部：负责劳动合同的统一管理，包括合同起草、签订组织、续签跟踪、解除/终止办理
2. 法务部：负责合同条款的合法性审查，劳动纠纷案件的处理
3. 部门负责人：协助HR做好本部门员工的合同管理和入职引导
4. 员工本人：如实提供个人信息，认真阅读合同条款，妥善保管本人合同

## 第二章 劳动合同签订

### 第四条 签订时间

1. 新入职员工须在入职当天签订书面劳动合同
2. 最晚不超过用工之日起30天内完成签订
3. 超过一个月未签合同的，从第二个月起支付双倍工资（法定要求）
4. 劳动合同一式两份，公司盖章后一份交员工本人，一份由HR部门存档

### 第五条 合同类型与期限

1. **固定期限劳动合同：**
   - 首次签订：一般为3年（试用期3-6个月）
   - 第二次续签：3-5年
   - 关键技术/管理岗位：可签订5年期合同

2. **无固定期限劳动合同：**
   - 满足以下条件之一的员工可申请签订无固定期限合同：
     a) 在公司连续工作满10年
     b) 连续签订两次固定期限合同后第三次续签的
     c) 距法定退休年龄不足10年的老员工

3. **以完成一定工作任务为期限的劳动合同：**
   - 适用于明确的短期项目制工作
   - 任务完成后合同自动终止

4. **实习协议：** 适用于全日制在校学生，期限不超过毕业日期

### 第六条 合同内容

劳动合同应包含以下条款（法定必备条款）：
1. 合同双方基本信息（公司全称、法定代表人、员工姓名、身份证号）
2. 合同期限（起止日期、试用期）
3. 工作内容与工作地点
4. 工作时间与休息休假
5. 劳动报酬（工资标准、发放日期）
6. 社会保险与福利待遇
7. 劳动保护与劳动条件
8. 竞业限制与保密条款（适用人员）
9. 劳动合同解除/终止条件
10. 违约责任

### 第七条 试用期约定

| 合同期限 | 试用期上限 |
|---------|----------|
| 3个月以上不满1年 | 1个月 |
| 1年以上不满3年 | 2个月 |
| 3年及以上 | 6个月 |
| 无固定期限 | 6个月 |

注：同一员工只能约定一次试用期。劳动合同仅约定试用期的，试用期不成立，该期限为劳动合同期限。

## 第三章 合同履行与变更

### 第八条 合同履行

1. 公司和员工双方应按照合同约定全面履行各自义务
2. 公司不得以任何形式强迫员工违反意愿提供劳动
3. 员工应遵守公司依法制定的规章制度和劳动纪律
4. 公司应为员工提供合同约定的劳动条件、劳动保护和福利待遇

### 第九条 合同变更

劳动合同的变更包括：工作内容变更、工作地点变更、薪酬调整、岗位调整等。
变更程序：
1. 变更提议方提出书面变更意向
2. 双方协商一致
3. 签订《劳动合同变更协议》（或重新签订合同）
4. 变更后的合同/协议双方各持一份
5. 涉及薪酬调整的从变更协议约定的生效日期开始执行

### 第十条 特殊情况处理

1. **公司合并/分立：** 原劳动合同继续有效，由承继权利义务的用人单位继续履行
2. **借调：** 员工借调至关联公司/合作方工作不超过6个月的，无须变更劳动合同主体；超过6个月的须签订借调协议明确各方权利义务
3. **工伤期间：** 员工在停工留薪期内，原工资福利待遇不变
4. **女员工"三期"（孕期、产期、哺乳期）：** 劳动合同到期时自动顺延至"三期"结束

## 第四章 合同续订与终止

### 第十一条 合同续订

1. 合同到期前60天，HR系统自动提醒，HR部门启动续订/终止评估
2. 合同到期前30天，部门负责人完成续订评估表（是否续订、续订期限、薪酬调整建议）
3. 合同到期前15天，HR与员工面谈确认续订意向
4. 双方同意续订的，合同到期前完成新合同签订
5. 公司不同意续订的，按解除劳动合同处理，支付经济补偿金
6. 员工不同意续订的（公司维持或提高条件），无须支付经济补偿金

### 第十二条 合同终止情形

有下列情形之一的，劳动合同终止：
1. 劳动合同期满且双方不再续订
2. 员工开始依法享受基本养老保险待遇（退休）
3. 员工死亡或被人民法院宣告死亡/失踪
4. 公司被依法宣告破产
5. 公司被吊销营业执照、责令关闭、撤销
6. 法律、行政法规规定的其他情形

### 第十三条 经济补偿金

经济补偿金计算标准：
- 每满一年支付一个月工资
- 六个月以上不满一年的按一年计算
- 不满六个月的支付半个月工资
- 月工资标准：劳动者解除/终止合同前12个月的平均工资
- 月工资超过本地区上年度职工月平均工资3倍的，按3倍封顶计算（最长12年）

## 第五章 劳动合同解除

### 第十四条 员工主动解除（辞职）

1. 试用期内：提前3日通知公司
2. 正式员工：提前30日书面通知公司
3. 辞职流程：
   - 提交《辞职申请书》→直属上级面谈→HR离职面谈→工作交接→财务结算→离职
4. 未按规定提前通知造成公司损失的，应承担相应责任
5. 公司收到辞职通知后应在15个工作日内安排离职面谈

### 第十五条 公司解除劳动合同

**即时解除（员工无补偿金情形）：**
- 在试用期间被证明不符合录用条件的
- 严重违反公司规章制度的（如旷工连续3天或年累计5天、泄露公司商业秘密、收受贿赂）
- 严重失职、营私舞弊，给公司造成重大损害的（直接经济损失≥5万元）
- 员工同时与其他用人单位建立劳动关系，经公司提出后拒不改正的
- 采用欺诈、胁迫手段使公司在违背真实意思情况下订立合同的
- 被依法追究刑事责任的

**提前30日通知解除（支付补偿金情形）：**
- 员工患病/非因工负伤，医疗期满后不能从事原工作也不能从事另行安排的工作
- 员工不能胜任工作，经培训或调岗后仍不能胜任的（须有两次书面考核记录）
- 客观情况发生重大变化（如部门撤销），合同无法继续履行，双方无法协商变更的
- 经济性裁员：依照法定程序进行

### 第十六条 解除程序规范

1. 公司单方解除劳动合同须事先将理由通知工会
2. 出具《解除/终止劳动合同证明书》
3. 在解除/终止后15日内为员工办理社保和档案转移手续
4. 涉及经济补偿金的，在办结工作交接时一次性支付
5. 《解除/终止劳动合同证明书》须载明：合同期限、解除/终止日期、工作岗位、本单位工作年限

## 第六章 劳动争议处理

### 第十七条 争议类型

常见劳动争议类型：
1. 工资报酬争议（加班费、绩效工资、年终奖等）
2. 劳动合同解除/终止争议
3. 工伤认定及待遇争议
4. 社会保险缴纳争议
5. 竞业限制经济补偿争议
6. 服务期违约金争议

### 第十八条 争议解决途径

1. **协商：** 员工与公司直接协商解决（推荐优先选择）
2. **调解：** 向公司劳动争议调解委员会或所在地劳动调解组织申请调解
3. **仲裁：** 向劳动争议仲裁委员会申请仲裁（争议发生后一年内提出）
4. **诉讼：** 对仲裁裁决不服的，在收到裁决书后15日内向人民法院提起诉讼

### 第十九条 公司内部申诉渠道

1. 直接上级：员工遇到劳动用工问题可首先向直接上级反映
2. HR部门：设立"员工关系专员"岗位，负责处理员工劳动用工咨询和诉求
3. HR总监：对处理结果不满意的可向HR总监申诉
4. 总经理信箱：重大事项可向总经理邮箱匿名或实名投递
5. 公司在5个工作日内对申诉给出答复

## 第七章 入职管理

### 第二十条 录用条件确认

1. 《录用通知书》须明确录用岗位、薪酬待遇、报到时间、报到时需携带的材料
2. 入职时签署《录用条件确认书》，明确试用期考核标准和转正条件
3. 发现员工提供虚假学历、虚假工作经历等欺诈行为的，解除劳动合同不支付补偿

### 第二十一条 入职手续

详见《员工手册》第二章第五条。

### 第二十二条 背景调查

1. 所有正式员工入职前进行背景调查
2. 调查内容：学历验证、工作经历核实、职业资格验证
3. 关键岗位（财务、技术核心、高管）额外审查：信用记录、犯罪记录、竞业限制情况
4. 背景调查须征得候选人书面同意
5. 背景调查结果有效期为6个月
6. 背景调查不通过的，公司有权撤回录用通知

## 第八章 员工档案管理

### 第二十三条 档案内容

员工个人档案包括：
1. 基本信息：身份证复印件、学历学位证书复印件、户口信息
2. 入职材料：录用通知书、录用条件确认书、入职登记表
3. 合同文件：劳动合同、保密协议、竞业限制协议、培训服务协议
4. 考核记录：试用期评估表、绩效考核结果、奖惩记录
5. 变更记录：调岗调薪记录、晋升记录
6. 离职记录：辞职申请、离职面谈表、离职证明存根

### 第二十四条 档案管理

1. 员工档案由HR部门统一保管，按员工编号归档
2. 纸质档案存放于带锁档案柜，电子档案存储于HR系统
3. 档案查阅须经HR经理审批，仅限工作需要查阅
4. 离职员工档案自离职之日起至少保存2年
5. 档案销毁须经HR总监审批并记录销毁日志

## 第九章 附则

### 第二十五条 制度的维护

本制度由人力资源部负责解释和修订。与本制度冲突的以往规定同时废止。
