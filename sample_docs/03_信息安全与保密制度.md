# 信息安全与保密制度

## 第一章 总则

### 第一条 目的

为保护公司信息资产安全，防范信息泄露风险，规范员工信息安全行为，根据《中华人民共和国网络安全法》《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》等法律法规，结合公司实际，制定本制度。

### 第二条 适用范围

本制度适用于公司全体员工（含实习生、劳务派遣人员）、驻场外包人员和所有接触公司信息资产的外部人员。

### 第三条 信息资产定义

本制度所指的信息资产包括但不限于：
1. 电子数据：源代码、数据库、设计文档、技术方案、客户信息、合同协议、财务报表、商业计划等
2. 纸质文档：合同原件、财务凭证、会议纪要、人事档案等
3. 软件系统：自主研发软件、采购的商业软件、SaaS平台账号等
4. 通信内容：邮件、即时通讯记录、音视频会议内容等
5. 知识产权：专利、商标、著作权、商业秘密等
6. 基础设施：服务器、网络设备、安全设备等的配置信息

## 第二章 信息分级与标识

### 第四条 信息密级分类

公司信息根据保密程度分为四个等级：

| 密级 | 标识 | 定义 | 示例 |
|-----|------|------|------|
| 绝密 | 红色"绝密"标识 | 泄露将导致公司遭受特别严重损害的敏感信息 | 核心算法、并购方案、未公开的融资信息、高管薪酬 |
| 机密 | 橙色"机密"标识 | 泄露将导致公司遭受严重损害的内部信息 | 客户名单、竞标方案、产品路线图、合同条款、薪酬数据 |
| 内部 | 黄色"内部"标识 | 泄露将导致公司遭受一般损害的工作信息 | 内部流程制度、项目计划、会议纪要、组织架构 |
| 公开 | 绿色"公开"标识 | 可对外公开的信息 | 产品宣传资料、年报、招聘信息、新闻稿 |

### 第五条 信息标识要求

1. 所有纸质文档须在封面和每页页眉标注密级标识
2. 电子文档须在文件名中添加密级前缀（如"[绝密]xxx"、"（内部）xxx"）
3. 邮件发送时须在标题中注明密级
4. 信息资产创建者负责确定初始密级
5. 密级可根据业务需要调整，调整须经信息所有人审批

## 第三章 访问控制与权限管理

### 第六条 最小权限原则

1. 员工仅能访问工作职责所需的信息，遵循"按需知悉"原则
2. 信息系统的权限按角色分配，权限变更须经审批
3. 离职员工的所有系统权限须在最后工作日当天关闭
4. 岗位变动的员工，旧岗位权限须在转岗当天收回
5. 每季度进行一次权限审计，清理冗余权限

### 第七条 身份认证

1. 所有信息系统的用户登录须使用公司统一账号
2. 账号密码要求：长度不少于12位，包含大小写字母、数字和特殊字符
3. 重要系统（财务、HR、客户数据等）须开启双因素认证（2FA）
4. 密码不得与他人共享，不得使用浏览器"记住密码"功能保存工作系统密码
5. 每90天修改一次密码，新密码不得与前5次密码重复
6. 发现密码泄露须立即修改并报告信息安全部门

### 第八条 物理安全

1. 办公区域实行门禁管理，员工凭工牌进出
2. 非公司人员来访须登记并佩戴访客证，由接待人员全程陪同
3. 绝密级和机密级文档须存放在带锁的文件柜中
4. 含有敏感信息或重要数据的办公区域须安装监控
5. 废弃的纸质文档须使用碎纸机销毁（机密级以上须使用横切式碎纸机）
6. 最后离开办公室的员工应检查门窗是否关闭、重要设备是否上锁
7. 未经审批，外部人员不得在公司内部拍照或录像

## 第四章 网络安全

### 第九条 网络使用规范

1. 办公网络为公司运营基础，仅供工作用途使用
2. 严禁私自搭建无线网络热点或将办公网络共享给外部设备
3. 禁止使用VPN、代理等方式绕过公司网络安全策略访问受限网站
4. 公司网络活动受合规监控，员工不得在工作网络中进行违法或违规操作（如下载盗版软件、访问非法网站等）
5. 未经授权，不得对公司网络进行端口扫描、漏洞探测等行为

### 第十条 设备安全

1. 公司配发的电脑、手机等设备仅限本人使用，不得转借他人
2. 员工须安装公司指定的终端安全软件（防病毒、DLP数据防泄露等），不得擅自卸载
3. 操作系统和安全补丁须及时安装更新，不得延期超过7天
4. 离开工位时须锁定计算机屏幕（Windows快捷键Win+L）
5. 移动存储设备（U盘、移动硬盘）使用前须杀毒，禁止使用来路不明的存储设备
6. 设备丢失或被盗须在发现后2小时内向信息安全部门和行政部门报告
7. 公司设备中的工作数据属于公司资产，公司有权远程擦除丢失设备中的数据
8. 机房等核心设备区域须双人同时在场方可操作，所有设备操作须有变更记录

### 第十一条 远程办公安全

1. 远程办公须使用公司批准的VPN接入公司网络
2. 严禁在公共WiFi环境下访问公司敏感系统
3. 远程办公时不得在公司设备上安装未经批准的远程控制软件
4. 在家远程办公时，工作屏幕不得被家庭成员观看
5. 远程打印含敏感信息的文件，须确保打印机在安全环境中

## 第五章 数据保护

### 第十二条 数据分类与保护

1. 所有结构化数据和非结构化数据均须按公司数据分类政策进行分级保护
2. 个人隐私数据（含员工和客户）须脱敏处理后方可在非生产环境中使用
3. 生产数据不得用于测试环境（经脱敏处理的除外），如需使用须提交数据脱敏申请
4. 数据保留期限按照法律要求和业务需求确定，过期数据定期清理
5. 数据备份须加密存储，备份数据的访问须经审批

### 第十三条 数据传输

1. 机密级以上信息通过邮件发送时须加密或使用安全链接
2. 大文件传输须使用公司指定的安全文件传输平台
3. 禁止通过私人邮箱、个人云盘、社交媒体等非公司平台传输工作文件
4. 使用即时通讯工具传输文件时须确认接收人身份
5. 通过外部存储设备传输数据的，须进行登记和审批
6. 跨部门传输机密级以上数据的，接收方须确认后回执

### 第十四条 数据备份与灾备

1. 核心业务数据每日自动备份，备份数据保留30天
2. 重要数据每月进行全量备份，异地存储，保留12个月
3. 每年进行一次灾难恢复演练，验证备份数据可用性
4. 备份数据须加密存储，访问备份数据须经审批
5. 过期备份数据按数据销毁流程处理

## 第六章 保密管理

### 第十五条 保密义务

1. 员工入职时须签署《保密协议》，保密义务在离职后仍然有效
2. 员工不得泄露公司商业秘密、技术秘密、经营信息等非公开信息
3. 员工不得利用公司保密信息从事个人投资或为他人提供咨询
4. 员工的保密义务涵盖电子和口头的各种形式的信息传递
5. 在公共场所（如电梯、餐厅、公共交通工具）不得讨论公司涉密事项
6. 离职时须交还所有含公司信息的载体（纸质/电子），不得私自留存

### 第十六条 外部沟通管理

1. 接受媒体采访须经公关部门审批，由指定发言人对外发言
2. 社交媒体发言须遵守《员工社交媒体使用规范》
3. 参加行业会议/论坛时，演讲内容须经部门负责人审核
4. 与合作方交流时，须签署保密协议（NDA）后方可披露必要信息
5. 对外发布产品信息、技术方案须经产品和技术负责人审批

### 第十七条 竞业限制

1. 高级管理人员、核心技术骨干、高级销售人员签署竞业限制协议
2. 竞业限制范围、地域、期限在劳动合同中明确约定
3. 竞业限制期限内公司按月支付经济补偿
4. 违反竞业限制的，须向公司支付约定的违约金

## 第七章 安全事件管理

### 第十八条 安全事件分级

| 级别 | 定义 | 响应时间 |
|-----|------|---------|
| 一级（特别重大） | 核心系统被入侵、大规模数据泄露、核心商业秘密外泄 | 30分钟内启动应急响应 |
| 二级（重大） | 重要系统异常、少量敏感数据泄露、疑似APT攻击 | 2小时内启动应急响应 |
| 三级（较大） | 办公终端病毒爆发、钓鱼邮件攻击、一般性安全告警 | 4小时内启动应急响应 |
| 四级（一般） | 单台设备异常、低风险漏洞、垃圾邮件 | 24小时内处理 |

### 第十九条 事件报告与处置

1. 发现信息安全事件后，员工须在30分钟内向信息安全部门报告
2. 禁止未经授权自行处置安全事件或对外披露事件信息
3. 信息安全部门接到报告后按事件级别启动应急预案
4. 事件处置完成后72小时内提交事件分析报告
5. 涉及个人信息泄露的，须按《个人信息保护法》规定在72小时内向监管部门报告
6. 安全事件不得隐瞒不报，瞒报行为将从严处理

### 第二十条 常见安全事件处理流程

**钓鱼邮件：** 收到疑似钓鱼邮件后严禁点击链接或下载附件，立即通过企业微信"信息安全举报"通道转发给安全团队进行研判。被确认为钓鱼邮件后，安全团队向全公司发布预警通知。

**设备丢失：** 第一时间联系直接上级和信息安全部门，信息安全部门远程锁定设备并启动数据擦除流程。员工须书面说明遗失经过，行政部协助办理报案及保险理赔。

**账号被盗：** 立即联系信息安全部门冻结账号，修改所有关联系统的密码，排查被盗期间的操作记录。信息安全部门评估影响范围并采取补救措施。

**敏感信息误发：** 发现工作信息误发给错误接收方后，立即联系对方要求删除并不得传播，同时报告直接上级和信息安全部门。信息安全部门评估泄露风险并决定是否需要升级处置。

## 第八章 合规与审计

### 第二十一条 日志与审计

1. 所有信息系统须开启操作日志记录功能
2. 核心系统的操作日志保留不少于12个月
3. 信息安全部门每季度对系统访问日志进行审计
4. 异常操作行为（非工作时间访问、大量数据导出等）触发告警
5. 所有安全审计发现的问题须在规定期限内整改完毕

### 第二十二条 安全培训

1. 新员工入职时须完成信息安全基础培训并通过考试（90分及格）
2. 全体员工每年须完成信息安全年度培训（不少于4学时）
3. 每季度至少组织一次钓鱼邮件模拟演练
4. 开发人员额外完成安全编码培训
5. 管理人员额外完成信息安全管理培训
6. 培训不合格者须补考，连续两次不合格的记入绩效考核

## 第九章 违规处理

### 第二十三条 违规行为等级

1. **一般违规：** 未造成实际损失的轻微违规行为，如密码不符合复杂度要求、离开工位未锁屏、使用非授权USB设备
2. **较重违规：** 造成一定损失或风险的违规行为，如使用个人邮箱发送工作文件、私自在公司设备安装未经批准的软件、将访客带入非授权区域
3. **严重违规：** 造成重大损失或风险的违规行为，如故意泄露公司商业秘密、越权访问他人隐私数据、盗取公司源代码、恶意破坏公司信息系统

### 第二十四条 处理措施

1. 一般违规：口头警告 + 信息安全补训
2. 较重违规：书面警告 + 罚款500-2000元 + 纳入绩效评估
3. 严重违规：解除劳动合同 + 追究法律责任 + 赔偿公司损失
4. 造成第三方损失的，公司有权向责任人追偿
5. 构成犯罪的，移交司法机关处理

## 第十章 附则

### 第二十五条 制度的维护

本制度由信息安全部负责解释、维护和修订。修订须经信息安全管理委员会批准后发布。
