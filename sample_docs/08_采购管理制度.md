# 采购管理制度

## 第一章 总则

### 第一条 目的

为规范公司采购行为，加强采购管理，降低采购成本，保证采购质量，防范采购风险，提高采购效率，特制定本制度。

### 第二条 适用范围

本制度适用于公司所有物资和服务的采购活动，包括但不限于：
1. IT设备及软件（计算机、服务器、网络设备、软件许可、SaaS服务）
2. 办公用品与设备（文具、家具、打印耗材）
3. 营销与推广服务（广告投放、市场活动物料、设计服务）
4. 专业服务（咨询、审计、法律、翻译、猎头服务）
5. 工程与装修
6. 差旅服务（机票酒店预订、车辆租赁）
7. 员工福利（体检、团建、节日礼品）

### 第三条 基本原则

1. 集中采购：归口采购部门统一执行，减少分散采购带来的管理漏洞
2. 阳光采购：公开透明、过程留痕，杜绝暗箱操作
3. 性价比优先：在满足质量和服务要求的前提下，选择综合性价比最优的供应商
4. 不相容职务分离：需求提出、供应商选择、合同审批、验收付款须由不同人员执行
5. 供应商竞争：达到比价标准的采购须至少三家供应商参与

## 第二章 采购组织与职责

### 第四条 采购组织

1. **采购部：** 负责采购执行、供应商开发与管理、价格谈判、合同签订
2. **需求部门：** 负责提出采购需求和技术规格要求、参与技术评审、合同验收
3. **财务部：** 负责采购预算审核、付款审核与执行
4. **法务部：** 负责合同条款的法律审查
5. **IT部门：** 负责IT类采购的技术评审（参与IT类采购的技术评分）
6. **审计部：** 对采购活动进行事后审计

### 第五条 采购审批权限

| 采购金额（单项/批次） | 审批层级 |
|--------------------|---------|
| 低于5000元 | 部门经理 |
| 5000-50000元 | 分管总监 + 采购经理 |
| 50000-200000元 | 采购总监 + 财务总监 |
| 200000-1000000元 | 总经理 |
| 超过1000000元 | 董事长/董事会 |

## 第三章 采购方式

### 第六条 采购方式分类

| 采购方式 | 适用条件 | 说明 |
|---------|---------|------|
| 直接采购 | 金额＜5000元 | 选择信誉良好的常用供应商直接下单 |
| 比价采购 | 5000元≤金额＜5万元 | 至少向3家供应商询价对比 |
| 竞争性谈判 | 5万元≤金额＜50万元 | 邀请不少于3家供应商进行方案和价格谈判 |
| 公开招标 | 金额≥50万元 | 公开发布招标公告，5家以上供应商参与 |
| 单一来源采购 | 专利/专有技术/特定授权/紧急情况 | 只能从唯一供应商处采购，须附情况说明并单独审批 |

### 第七条 比价采购流程

1. 需求部门提交采购申请（附规格参数/服务要求）
2. 采购部向3家以上合格供应商发送询价函
3. 供应商在截止日期前提交报价和技术方案
4. 采购部编制《比价分析表》（对比价格、方案、交期、服务等）
5. 选择最优供应商，按审批权限报批
6. 签订采购合同
7. 跟踪交付并组织验收

### 第八条 招标采购流程

1. 需求部门提交经批准的采购申请和招标需求书
2. 采购部编制招标文件（商务条款+技术规格），发布招标公告（不少于7个自然日）
3. 供应商购买/下载招标文件，提交投标文件
4. 开标：在规定时间和地点公开开标
5. 评标：评标委员会（5人及以上单数，含技术、商务、财务代表）进行技术和商务评分
6. 定标：按综合得分排名确定中标供应商
7. 中标公示（不少于3个工作日）
8. 公示无异议后发《中标通知书》、签订合同

### 第九条 应急采购

1. 应急采购适用于：
   - 生产/运行设备突发故障影响正常经营
   - 安全事件引发的紧急物资需求
   - 客户服务Level 1故障所需备件
   - 自然灾害等不可抗力的紧急应对
2. 应急采购可先口头请示后采购，事后3个工作日内补办书面审批
3. 应急采购金额超过10万元的，须事后向审计部门备案

## 第四章 供应商管理

### 第十条 供应商准入

1. 新供应商须通过供应商准入审核后方可合作
2. 准入审核材料：
   - 营业执照（经营范围须与实际业务匹配）
   - 行业资质证书（如ISO认证、经营许可）
   - 近三年财务报表或审计报告
   - 银行资信证明
   - 同类客户合作案例（至少2个）
   - 法定代表人和实际控制人信息
3. 供应商须签署《供应商行为准则》和《保密协议》
4. 与公司董事、高管、采购人员存在利益关联的供应商须申报并回避

### 第十一条 供应商评估与分级

1. 年度供应商评估在每年12月进行
2. 评估维度：质量（30%）、价格（25%）、交货（20%）、服务（15%）、合规（10%）
3. 评估等级：
   - A级（优秀，≥90分）：优先合作，增加采购份额
   - B级（良好，75-89分）：正常合作
   - C级（一般，60-74分）：限制合作，减少采购份额
   - D级（不良，＜60分）：终止合作，从合格供应商名录中移除
4. 评估结果通过供应商管理系统记录

### 第十二条 供应商黑名单

以下行为的供应商列入黑名单，永不合作：
1. 提供虚假资质或虚假产品信息
2. 商业贿赂
3. 严重违约给公司造成重大损失（直接损失≥10万元）
4. 泄露公司商业秘密
5. 串通投标、围标
6. 被列入失信被执行人名单

## 第五章 合同管理

### 第十三条 合同签订

1. 单次采购金额≥2万元的须签订书面采购合同
2. 金额＜2万元的可用采购订单代替（但须包含交易关键条款）
3. 合同须使用公司法务部审核的标准合同模板。非标合同变更须法务部审核
4. 合同须经双方授权代表签字并加盖公章/合同专用章
5. 采购合同原件由采购部和财务部各持一份

### 第十四条 合同关键条款

采购合同应包含以下条款：
1. 双方基本信息
2. 采购标的物/服务的详细描述和技术规格
3. 价格、计价方式和付款条件（含税率）
4. 交货期/服务期限
5. 交货地点和运费承担
6. 验收标准和验收期限
7. 质保期和售后服务承诺
8. 付款方式（首付+验收+质保金分期）
9. 违约责任和赔偿条款
10. 知识产权归属（涉及软件/设计/研发的）
11. 保密条款
12. 不可抗力条款
13. 争议解决方式

### 第十五条 合同执行

1. 采购部负责跟踪合同执行进度，关键节点向需求部门通报
2. 合同变更须签订书面变更协议，原审批流程重新审批
3. 合同纠纷由采购部协同法务部处理
4. 合同履约结束后进行供应商履约评价

## 第六章 验收与付款

### 第十六条 验收管理

1. 需求部门负责验收，验收依据为合同约定的技术规格和验收标准
2. 验收参与人：需求部门代表和采购部代表；≥20万元的项目须增加第三方/质检
3. 验收期限：一般物资5个工作日，设备/工程/软件10个工作日
4. 验收结果：
   - 合格：签署《验收报告》，进入付款流程
   - 不合格：出具《不合格报告》，供应商在约定期限内整改或更换
   - 让步接收：需求部门评估后可降低标准接收，但须按合同约定扣减价款
5. 验收报告是付款的必要凭证

### 第十七条 付款管理

1. 按合同约定的付款节点和比例付款
2. 付款申请附：采购合同、验收报告、发票、采购申请单
3. 质保金一般为合同金额的5%-10%，质保期满后退还
4. 预付款原则上不超过合同金额的30%，须有对应担保措施
5. 所有采购付款须通过银行转账至供应商对公账户
6. 发票须为增值税专用发票（供应商为一般纳税人的）或普通发票

## 第七章 采购监督与审计

### 第十八条 采购监督

1. 采购决策过程须全程留痕
2. 审计部每半年对采购活动进行审计
3. 所有员工有权对采购违规行为进行举报，举报人受保护

### 第十九条 违规处理

1. 一般违规（未严格遵守流程但未造成损失）：通报批评，限期整改
2. 较重违规（绕开比价/招标流程、拆分合同规避审批）：书面警告 + 罚款1000-5000元
3. 严重违规（收受供应商利益、虚假报账、围标串标）：解除劳动合同 + 追究法律责任
4. 供应商贿赂的，该供应商列入黑名单
