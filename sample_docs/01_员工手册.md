# 员工手册

## 第一章 公司概况

### 第一条 公司简介

本公司成立于2005年，是一家专注于企业级软件研发与信息技术服务的高新技术企业，总部位于北京，在上海、深圳、成都、武汉设有分支机构，现有员工约3000人。公司已通过ISO 9001质量管理体系认证、ISO 27001信息安全管理体系认证和CMMI 5级认证。

### 第二条 公司使命与价值观

公司使命：以技术创新推动企业数字化转型，为客户创造可持续的商业价值。

核心价值观：
- 客户至上：始终以客户需求为导向，超越客户期望
- 创新驱动：鼓励技术创新和思维创新，拥抱变化
- 诚信正直：坚持最高的职业道德标准，言行一致
- 团队合作：倡导开放协作的团队文化，共同成长
- 追求卓越：持续学习，精益求精，拒绝平庸

### 第三条 适用范围

本手册适用于公司全体员工（含试用期员工）。劳务派遣人员、实习生、外包人员参照本手册相关条款执行。各部门可根据业务特点在本手册框架内制定部门级补充规定，但不得与本手册冲突。

## 第二章 入职管理

### 第四条 入职材料

新员工入职时须提交以下材料：
1. 本人有效身份证件原件及复印件（正反面）
2. 最高学历证书、学位证书原件及复印件
3. 上一家单位出具的离职证明（应届毕业生除外）
4. 近三个月内二级甲等以上医院出具的体检报告
5. 本人名下银行卡复印件（用于工资发放）
6. 一寸白底免冠照片电子版及纸质版2张
7. 社保公积金转移单（如有）
8. 专业技术资格证书、职业资格证书复印件（如有）

### 第五条 入职流程

1. 入职前一周：HR发送《入职通知书》，确认入职时间和所需材料
2. 入职当天上午（9:00-10:00）：HR办理入职手续，核验材料，签订劳动合同
3. 入职当天上午（10:00-11:00）：IT部门发放办公设备，配置系统账号
4. 入职当天下午（14:00-16:00）：参加新员工入职培训（公司介绍、制度宣导、安全教育）
5. 入职当天下午（16:00-17:30）：到所属部门报到，部门安排导师
6. 入职第一周：完成线上安全培训课程并通过考试
7. 入职一个月内：完成岗位技能培训和业务知识学习

### 第六条 试用期管理

1. 劳动合同期限三年及以上的，试用期不超过六个月；合同期限一年以上不满三年的，试用期不超过三个月
2. 试用期内员工享受正式员工同等薪酬福利待遇（另有约定的除外）
3. 试用期内员工提前三日通知即可解除劳动合同
4. 试用期内如发现员工不符合录用条件，公司可随时解除劳动合同
5. 试用期结束前两周，部门负责人完成试用期考核评估
6. 试用期考核通过后正式转正，由HR办理转正手续
7. 试用期考核不通过的，公司有权解除劳动合同或延长试用期

## 第三章 薪酬福利

### 第七条 薪酬结构

员工薪酬由以下部分构成：
1. 基本工资：根据岗位职级确定，占总薪酬的60%-70%
2. 绩效工资：根据月度/季度绩效考核结果浮动发放，占总薪酬的20%-25%
3. 岗位津贴：根据岗位性质发放，如技术津贴、管理津贴、驻外津贴等
4. 年终奖金：根据公司年度经营业绩和个人年度绩效考核结果发放，一般为1-6个月基本工资

### 第八条 发薪规定

1. 发薪日为每月10日，遇节假日顺延至下一个工作日
2. 工资通过银行转账方式发放至员工本人银行卡
3. 每月发放工资时同时提供电子工资条，员工可通过HR系统查询
4. 新入职员工当月工资按实际工作天数折算
5. 离职员工最后一个月的工资在办理完离职手续后5个工作日内发放

### 第九条 社会保险与公积金

1. 公司依法为员工缴纳养老保险、医疗保险、失业保险、工伤保险、生育保险
2. 公司依法为员工缴纳住房公积金
3. 社保和公积金缴纳基数按国家和地方政策规定执行，每年7月调整基数
4. 补充商业保险：公司为正式员工购买补充医疗保险（含门诊、住院、重大疾病）和意外伤害保险，保障额度为年薪的24倍

### 第十条 其他福利

1. 带薪休假：年假、婚假、产假/陪产假、丧假、病假等按国家规定执行
2. 年度体检：每年组织一次全员健康体检，标准不低于800元/人
3. 节假日福利：春节、端午、中秋等传统节日发放节日礼品或礼金
4. 生日福利：员工生日当月发放200元生日礼金或等值礼品
5. 通讯补贴：根据岗位级别每月补贴100-300元
6. 餐饮补贴：工作日提供免费午餐，或补贴25元/工作日
7. 交通补贴：每月交通补贴200元，驻外人员按实际差旅费用报销
8. 团建活动：每季度每人200元团建经费，部门统一组织活动
9. 学习发展：每人每年最高5000元培训经费，可用于外部培训、考证、购买书籍等
10. 员工关怀：结婚礼金1000元、生育礼金1000元、丧事慰问金500元

## 第四章 考勤与休假

### 第十一条 考勤管理

详见《员工考勤管理制度》。

### 第十二条 带薪年假

1. 累计工作满1年不满10年：每年5天
2. 累计工作满10年不满20年：每年10天
3. 累计工作满20年：每年15天
4. 年假最小请假单位为半天（4小时）
5. 年假当年有效，可申请延期至次年3月31日，逾期作废
6. 离职时未休年假按日工资标准折算补偿

### 第十三条 婚假

1. 符合法定结婚年龄的员工，享受婚假3天
2. 符合晚婚条件的（男满25周岁、女满23周岁），额外增加婚假7天
3. 婚假须在结婚登记之日起一年内一次性休完
4. 婚假期间工资照常发放

### 第十四条 产假与陪产假

1. 女性员工产假：98天（产前15天+产后83天），难产增加15天，多胞胎每多一胎增加15天
2. 符合计划生育政策的，额外享受生育奖励假30天
3. 男性员工陪产假：15天
4. 哺乳假：子女未满1周岁的女性员工，每日享受1小时哺乳时间（可分两次使用）
5. 产假/陪产假期间工资按生育保险规定执行，公司补足差额

### 第十五条 丧假

1. 直系亲属（父母、配偶、子女）去世：丧假3天
2. 祖父母、外祖父母、配偶父母去世：丧假2天
3. 兄弟姐妹去世：丧假1天
4. 外地奔丧的可另外申请路程假，往返路途时间按实际计算，最多不超过4天
5. 丧假期间工资照常发放

## 第五章 员工发展

### 第十六条 职级体系

公司建立双通道职业发展体系：
1. 管理通道（M序列）：M1主管→M2经理→M3高级经理→M4总监→M5高级总监→M6副总裁→M7总裁
2. 专业技术通道（P/T序列）：P1/T1初级→P2/T2中级→P3/T3高级→P4/T4资深→P5/T5专家→P6/T6高级专家→P7/T7首席专家/科学家
3. 管理通道与专业技术通道同级别薪酬待遇对等，员工可根据个人职业规划选择发展路径
4. 鼓励跨通道流动，员工可在管理通道和专业技术通道之间转换

### 第十七条 晋升机制

1. 每年1月和7月各组织一次晋升评审
2. 晋升基本条件：在当前职级工作满1年以上，最近两次绩效考核均为B+及以上
3. 晋升评审流程：提名→资格审核→答辩评审→评审委员会投票→结果公示→晋升任命
4. 破格晋升：对公司做出重大贡献或在技术创新方面取得突破性成果的员工，可不受任职年限限制
5. 晋升结果公示期为5个工作日，公示期内接受全体员工监督

### 第十八条 培训与学习

1. 新员工入职培训：公司制度、企业文化、安全教育、岗位基础技能
2. 在岗培训（OJT）：由直属上级或资深同事指导，在实际工作中学习成长
3. 内部技术分享：每周五下午举办技术分享会，鼓励员工分享知识和经验
4. 外部培训：员工可申请参加行业会议、技术培训、认证考试，公司提供培训经费支持
5. 在线学习平台：公司采购了主流在线学习平台的课程资源，员工可随时学习
6. 学历提升：员工在职攻读硕士及以上学历，毕业后与公司签订2年服务协议可报销50%学费

## 第六章 行为规范

### 第十九条 工作纪律

1. 爱护公司财产，不得擅自挪用或带离公司设备
2. 保持办公环境整洁、安静，不得在办公区域大声喧哗
3. 工作时间不得从事与工作无关的活动（如玩游戏、看视频、炒股等）
4. 同事之间相互尊重，不得有任何形式的骚扰、歧视、霸凌行为
5. 严格遵守公司信息安全和保密规定

### 第二十条 仪容仪表

1. 工作日着装以商务休闲为主，要求整洁、得体、大方
2. 每周五为"便装日"，可穿着商务休闲便装
3. 接待客户或参加正式会议时，要求穿着正装
4. 不得穿着过于暴露、邋遢或印有不恰当图案的服装
5. 注意个人卫生，保持良好精神面貌

### 第二十一条 利益冲突

1. 员工不得从事与公司业务有竞争关系的兼职工作
2. 员工及其直系亲属不得在与公司有业务往来的企业中持有权益（上市公司股票除外）
3. 员工不得利用职务便利为个人或他人谋取不正当利益
4. 员工不得接受供应商、客户的礼品、宴请（价值超过200元的礼品须上交公司）
5. 如存在潜在利益冲突，应主动向直属上级和HR部门声明

### 第二十二条 知识产权

1. 员工在工作期间利用公司资源完成的任何发明创造、技术成果、软件代码、文档等知识产权均归公司所有
2. 员工离职后一年内做出的、与原工作相关的发明创造，其知识产权仍归公司所有
3. 员工有权在自己的技术成果上署名，公司应予以承认
4. 公司对发明创造的发明人给予奖励（专利申请受理奖励5000元，专利授权奖励10000元）

## 第七章 离职管理

### 第二十三条 离职类型

1. 主动辞职：员工提前三十日（试用期提前三日）书面通知公司，可解除劳动合同
2. 协商解除：经双方协商一致，可解除劳动合同
3. 公司解除：因员工严重违纪、不符合录用条件或公司经营调整等原因解除劳动合同
4. 合同期满：劳动合同期满，双方不再续签
5. 退休：员工达到法定退休年龄，办理退休手续

### 第二十四条 离职流程

1. 提交申请：员工向直属上级和HR部门提交书面《离职申请书》
2. 离职面谈：HR安排离职面谈，了解离职原因，听取意见建议
3. 工作交接：填写《工作交接清单》，完成工作、文档、设备等交接
4. 财务结算：结清工资、报销、补偿金等款项
5. 归还物品：归还门禁卡、工牌、电脑设备、手机等公司财产
6. 办理社保/公积金转移手续
7. 开具《离职证明》

### 第二十五条 竞业限制

1. 高级管理人员、高级技术人员、核心业务人员签署竞业限制协议
2. 竞业限制期限最长不超过二年
3. 竞业限制期间，公司按月支付经济补偿金，标准为离职前十二个月平均工资的30%
4. 违反竞业限制约定的，需向公司支付违约金并承担相应法律责任

## 第八章 附则

### 第二十六条 制度修订

本手册由人力资源部负责维护和修订。修订须经工会或职工代表大会讨论通过，报公司总经理批准后发布。重大修订须提前30天公示。

### 第二十七条 解释权

本手册的解释权归公司人力资源部。员工对手册内容有疑问，可向直属上级或HR部门咨询。

### 第二十八条 生效日期

本手册自2024年1月1日起施行，原《员工手册（2022版）》同时废止。
