# 财务管理制度

## 第一章 总则

### 第一条 目的

为规范公司财务管理行为，加强内部控制，保障资产安全完整，保证会计信息真实准确，提高资金使用效益，根据《中华人民共和国会计法》《企业会计准则》等法律法规，结合公司实际情况，制定本制度。

### 第二条 适用范围

本制度适用于公司及其所属各部门、分支机构的财务管理工作。

### 第三条 基本原则

1. 合法性原则：严格遵守国家财经法律法规
2. 真实性原则：会计信息必须真实、准确、完整
3. 内部控制原则：不相容职务相互分离、相互制约
4. 成本效益原则：合理控制成本费用，提高经济效益

## 第二章 预算管理

### 第四条 预算编制

1. 公司实行全面预算管理，每年第四季度编制下年度预算
2. 各部门于每年11月15日前提交部门年度预算草案
3. 财务部汇总并编制公司年度预算，12月15日前报董事会审批
4. 年度预算经董事会批准后分解为季度预算和月度预算
5. 预算编制内容包含收入预算、成本预算、费用预算、资本支出预算、现金预算等部分
6. 各部门须对重大项目（10万元以上）提供详细的预算说明

### 第五条 预算执行与控制

1. 各部门须严格按照批准的预算执行，严禁无预算支出
2. 财务部每月初发布各部门预算执行情况报告
3. 季度预算执行偏差超过±15%的部门须提交偏差分析报告
4. 单个项目预算超支须提前提交追加预算申请，经财务总监和总经理批准
5. 年度内未使用的预算经费原则上不予结转下年，特殊情况（如跨年项目）除外
6. 应急/突发事件支出可先由总经理批准执行，事后30日内补办预算调整手续

### 第六条 预算调整

1. 半年度（7月）组织一次预算调整
2. 以下情况可申请预算调整：
   - 外部市场环境发生重大变化（如行业政策调整、主要客户流失）
   - 公司经营战略调整
   - 不可抗力事件
3. 预算调整申请须包括调整原因、调整金额、影响分析
4. 5万元以下调整由财务总监审批，5万-50万由总经理审批，50万以上需董事会审批

## 第三章 资金管理

### 第七条 银行账户管理

1. 公司银行账户的开立、变更、注销须经财务总监和总经理审批
2. 严禁以公司名义开立个人账户或使用个人账户存取公司资金
3. 银行预留印鉴实行分开保管：财务章由财务主管保管，法人名章由财务总监保管
4. 每月银行对账单须于次月5日前取得，由非出纳人员进行银行余额调节表编制
5. 网银操作实行双人审批制（一人录入一人复核），U盾由两人分别保管

### 第八条 现金管理

1. 库存现金限额为50,000元，超出部分须当日送存银行
2. 现金支付范围为：职工工资津贴、劳保福利、差旅费用、结算起点（2000元）以下的零星支出
3. 超过结算起点的支出须通过银行转账支付
4. 严禁坐支现金（即从现金收入中直接支付）、私设"小金库"
5. 出纳人员须每日盘点库存现金，编制现金日报表
6. 财务经理每周至少进行一次现金突击盘点

### 第九条 资金支付审批

| 金额范围 | 审批层级 |
|---------|---------|
| 低于5000元 | 部门经理 |
| 5000-20000元 | 分管总监 |
| 20000-100000元 | 财务总监 + 分管副总裁 |
| 100000-500000元 | 总经理 |
| 超过500000元 | 董事长/董事会 |

### 第十条 往来账款管理

1. 应收账款：销售部门为催收责任部门，30天以内为正常账期，30-60天为关注类，60-90天发送催款函，90天以上启动法律程序
2. 应付账款：财务部每月编制应付账款明细表，合理利用信用期，按时支付以维护供应商关系
3. 预付款项：金额超过5万元的预付款须提供担保或抵押
4. 其他应收款（备用金、借款）：个人借款须在3个月内结清，跨年度借款次年1月底前须全部清账
5. 每月计提坏账准备，单项金额超过10万元的应收账款单独进行减值测试
6. 客户信用政策：新客户先款后货或30%预付款，老客户评估后授予信用期

## 第四章 费用报销管理

### 第十一条 报销基本规定

1. 所有费用报销须遵循"先审批后支出"原则（日常固定费用除外）
2. 费用报销通过OA系统提交《费用报销单》，须提供真实、完整、合法的票据
3. 发票要求：增值税专用发票或普通发票，发票抬头为公司全称及纳税人识别号
4. 费用须在发生后30日内报销，跨年度费用须在次年1月31日前报销完毕
5. 报销单须经直属上级、财务审核、财务经理三级审批

### 第十二条 常见费用报销标准

**业务招待费：**
- 客户来访：人均不超过200元/餐
- 重要客户：人均不超过400元/餐（须提前申请）
- 招待费报销须附参与人员名单、招待事由、餐厅消费明细

**会议费：**
- 内部会议：不超过每天每人300元（含场地、茶歇）
- 外部会议：按实际参会费用报销，须附会议通知
- 超过500元/人的会议须提前审批

**培训费：**
- 个人年度培训预算为5000元
- 外部培训费超过2000元须签培训服务协议
- 培训在3000元以上的，自培训结束日算起须在公司服务满1年；否则按比例退还培训费用

**交通费：**
- 市内公出优先使用公共交通
- 加班至21:00后或早于6:30出发的，可报销出租车/网约车费用
- 私家车因公使用按1.2元/公里报销（含油费、过路费、停车费）

**通讯费：**
- 按岗位级别发放月度补贴，不单独报销通讯费用
- 标准：普通员工100元/月，经理级200元/月，总监级300元/月

### 第十三条 不予报销的费用

1. 无合法发票或发票不符合规定的费用
2. 发票内容与实际消费不符的费用
3. 超出标准的费用（超出部分）
4. 个人消费性质的费用（如娱乐、旅游、健身等）
5. 购买礼品卡等代币类费用（客户赠礼除外，须附赠礼名单）
6. 烟酒类消费（商务宴请中的合理酒类除外）
7. 超过报销期限的费用
8. 未获审批的费用

## 第五章 资产管理

### 第十四条 固定资产管理

1. 固定资产认定标准：使用年限超过一年，单位价值2000元以上的有形资产
2. 固定资产分为：房屋建筑物、机器设备、电子设备、运输设备、办公家具五大类
3. 固定资产须粘贴资产标签，标签含资产编号、名称、使用部门、购置日期
4. 每半年进行一次固定资产盘点（6月和12月），盘点差异须调查原因
5. 折旧政策：
   - 房屋建筑物：20年（残值率5%）
   - 电子设备（电脑、服务器）：3年（残值率5%）
   - 办公设备/家具：5年（残值率5%）
   - 运输设备：4年（残值率5%）

### 第十五条 无形资产管理

1. 无形资产包括：自行研发的软件产品、专利商标、版权、许可使用权、域名
2. 自行研发项目的支出在研发阶段费用化，满足资本化条件的可确认为无形资产
3. 无形资产摊销年限：合同约定期限的按合同，无约定的按10年
4. 每年末对无形资产进行减值测试
5. 转让或许可他人使用无形资产须经董事会批准

### 第十六条 存货管理

1. 存货包括：原材料、在产品、产成品、低值易耗品
2. 存货入库须办理验收手续，质量不合格的须办理退货或降级处理
3. 存货发出计价采用月末一次加权平均法
4. 每季度末进行全面盘点，贵重存货（单项价值＞5000元）每月盘点
5. 存货盘亏/毁损须查明原因，属于管理不善导致的追究相关人员责任
6. 存货按成本与可变现净值孰低计量，计提存货跌价准备

## 第六章 财务报告与分析

### 第十六条 财务报告

1. 月度财务报表于次月10日前编制完成
2. 季度财务报表于季末后15日内编制完成
3. 年度财务报告于次年1月31日前编制完成
4. 年度财务报告须经外部会计师事务所审计
5. 财务报告包括：资产负债表、利润表、现金流量表、所有者权益变动表及附注
6. 重大经营事项（如重大投资、资产重组）须在报表附注中充分披露

### 第十七条 财务分析

1. 月度经营分析会于次月15日前召开
2. 财务分析主要内容：
   - 收入分析：按产品/客户/区域维度的收入结构及同比环比变化
   - 成本分析：毛利率变化及影响因素
   - 费用分析：三大费用（销售、管理、研发）的预算执行率及异常波动
   - 现金流分析：经营活动现金净流量与净利润的差异分析
   - 关键指标：人均产值、研发投入占比、应收账款周转天数、存货周转天数

## 第七章 税务管理

### 第十八条 纳税申报

1. 财务部指定专人负责各项税种的申报和缴纳
2. 增值税：按月申报，每月15日前完成
3. 企业所得税：按季预缴，年度汇算清缴（次年5月31日前）
4. 个人所得税：按月代扣代缴
5. 印花税、城建税、教育费附加等按法定时限申报

### 第十九条 税务筹划

1. 充分利用高新技术企业所得税优惠（15%）、研发费用加计扣除（100%）、软件产品增值税即征即退等税收优惠政策
2. 重大业务安排在签订合同前须经税务审查
3. 发票管理须符合税法规定，严禁虚开、买卖、非法代开发票
4. 关联交易须符合独立交易原则，按规定准备同期资料
5. 每年聘请税务顾问对公司税务合规性进行健康检查

## 第八章 财务内控与审计

### 第二十条 财务内控

1. 不相容职务分离：出纳不得兼管稽核、会计档案保管和收入/费用/债权/债务账目登记
2. 授权审批控制：重大交易实行集体决策或联签制度
3. 会计系统控制：凭证连续编号、账簿定期打印、数据定期备份
4. 财产保护控制：定期盘点、限制未经授权人员接触财产
5. 预算控制：实际支出与预算偏差超过15%须分析说明
6. 财务岗位轮换：出纳岗位每2年轮换一次，其他财务岗位每3年轮换一次

### 第二十一条 内部审计

1. 内审部门独立于财务部门，直接向审计委员会报告
2. 每年进行一次全面的内部审计
3. 内审范围：财务收支审计、内部控制审计、经济责任审计
4. 审计发现的问题须在30日内整改完毕
5. 离任审计：部门经理以上人员离职/调岗须进行离任审计
